プライバシーポリシー

最終更新: 2026年9月12日

life-sleep-sync（以下「本ツール」）は、作者が自分自身のために運用する個人利用のツールです。 作者以外の利用者を受け付けていません。本ポリシーは、本ツールが扱うデータの取り扱いを説明します。

1. 取得する情報

本ツールは、Google Health API を通じて、認可した本人のアカウントから次の情報を読み取ります。

  • 睡眠に関するデータ（就寝・起床時刻、睡眠時間、睡眠ステージ）
  • 健康指標（血中酸素飽和度、呼吸数、心拍変動、安静時心拍、皮膚温）
  • 活動データ（歩数などのアクティビティ）

読み取りは readonly スコープのみを使用します。データの書き込み・変更・削除は行いません。

2. 利用目的

取得したデータは、作者本人の睡眠習慣の記録と振り返りにのみ使用します。 それ以外の目的には使用しません。

3. 保存場所

取得したデータは、作者本人が所有する非公開のGitHubリポジトリに、 Markdown形式のテキストとして保存されます。第三者はアクセスできません。

APIの認証情報（OAuthトークン）はGitHub Actionsのシークレットとして暗号化保存され、 リポジトリの内容として保存されることはありません。

4. 第三者提供

取得したデータを第三者に提供・販売・共有することはありません。 広告配信、行動解析、機械学習モデルの学習には一切使用しません。

5. Google ユーザーデータの取り扱い

本ツールによる Google API から取得した情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。

6. データの削除・アクセス権の取り消し

本ツールへのアクセス権は、 Google アカウントの権限設定 からいつでも取り消せます。取り消し後、本ツールはデータを取得できなくなります。 保存済みのデータは、リポジトリから削除することで消去できます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub @ebiken99 までご連絡ください。
